# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

Only the latest released version and the `main` branch receive security updates.

## Reporting a Vulnerability

We take security vulnerabilities seriously.  
Please **do not** report security issues through public GitHub Issues.

Instead, use **GitHub Security Advisories**:

1. Go to the [Security tab](https://github.com/artan-pg/artan-commons-utils/security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in the details of the issue.

Alternatively, you can start a draft security advisory directly from the repository’s Security page.

### What to include in your report

- A clear description of the vulnerability
- Steps to reproduce the issue
- Affected versions (if known)
- Potential impact
- Any proof-of-concept or exploit code (if available)

### Response Process

- You will receive an acknowledgment within a few days.
- We will investigate the report and keep you informed of our progress.
- Once the issue is resolved, we may publish a security advisory (with credit to you if desired).
- Please allow reasonable time for us to address the vulnerability before any public disclosure.

## Scope

This policy applies to the source code and published artifacts of this library.

The following are generally **out of scope**:

- Vulnerabilities in dependencies (please report them to the upstream project)
- Issues that require unrealistic user interaction or physical access
- Social engineering attacks

Thank you for helping keep Artan Commons Utils and its users safe.
